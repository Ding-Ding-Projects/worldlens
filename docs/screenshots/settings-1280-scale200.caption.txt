The Settings dialog at 1280x800 CSS pixels with the display scale factor set to 200% (deviceScaleFactor 2) through Chrome DevTools Protocol's Emulation.setDeviceMetricsOverride, dark theme, bilingual mode. The override was cleared before being set, which back-to-back calls without clearing were found to silently ignore. Real Electron app built from this repository, launched with --worldlens-direct-launch on a cheap Lowlevel hidden desktop, driven entirely through Chrome DevTools Protocol. This proves the interface renders without clipping or pixel-rounding artefacts at double device pixel density at a normal desktop width. It does not prove behaviour at 200% scale on a narrow window; see settings-640-scale200.png for that. Captured from the real built artifact at commit 6db5c74222ac98a25fea70918f8ea523c4990b77.
