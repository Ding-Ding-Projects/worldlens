Kid Mode's Explore view: the one screen in this whole shell where the real map canvas shows through its own chrome instead of being covered by it (`.wl-kid__map`'s own doc comment in KidShell.vue names this as the deliberate exception to every other kid-mode view painting an opaque surface over the entire window) - the free-flight controls, zoom buttons, control bar and main menu the #map slot forwards, over the same rendered map every other map capture in this run shows. Real Electron app. The map was rendered by upstream BlueMap Java engine, built from the vendored source from a synthetic world this repository generated (seed 1839200155, 1000x1000 blocks), and is served to the app over loopback by this repository's own map handler. What it proves is the viewer port, the embedded server and the reverse proxy. The TypeScript mesher in packages/engine rendered none of it.
