# Shell refresh, October 2026

Design record for the October 2026 shell refresh. It modernises the shipped shell inside the
existing Material 3 design system (`design/packages/design-system`): no new tokens, no removed
features. Open any `.dc.html` file in a browser to view it.

| Artboard | What it shows |
| --- | --- |
| `Main.dc.html` | Home: a one-line title bar with a version chip, a single non-wrapping status line, an extended navigation rail that separates destinations from job shortcuts, and a calmer Home with one primary action and six catalogue cards. |
| `Work.dc.html` | Work: labelled tab groups and actions, and a header above every open job (breadcrumb, title, purpose, actions). |
| `Servers.dc.html` | A job list: single-line card headers with ellipsized names, monospace metadata chips that never wrap, and a bulk bar that says why its actions are disabled. |

The artboards are design intent, not evidence. Screenshots of the shipped build live under
`docs/screenshots/` with their capture dates.
