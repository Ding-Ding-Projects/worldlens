# Worldlens UI — full source snapshot

This folder is the complete, fully written UI of Worldlens — a verbatim copy of
`design/packages/ui` (Vue 3 + Vuetify 3, Material Design 3 shell) as merged to `main`.

It sits next to the design references that produced it:

- `../Worldlens.dc.html` — the approved clickable prototype
- `../HANDOFF.md` — the design spec the rewrite was executed from

The authoritative, buildable package remains `design/packages/ui`; this copy exists so the
`redesign/` folder carries the finished UI alongside the design artifacts.
