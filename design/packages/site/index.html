Your Minecraft world, rendered into a 3D map.

{{ heroYue }}

A from-scratch TypeScript port of BlueMap, the Minecraft world renderer and 3D web map.

Render from a desktop application, or from a GitHub Actions run with nothing installed at all, and browse it in an interface rebuilt from the ground up in Material Design 3.

Download for Windows

Windows only, and permanently unsigned by choice — SmartScreen will warn. Rendering needs Java, which the app fetches into its own folder.

Which renderer runs today, in one sentence

A world you render locally is rendered by upstream BlueMap's own Java engine, built from the vendored source and driven by the application as a child process. The TypeScript mesher this project exists to write passed its byte-comparison parity gate on 2026-08-04 and still does not render anything in the product. Every render records which engine produced it.
