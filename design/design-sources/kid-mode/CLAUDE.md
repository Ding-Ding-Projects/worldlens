# Project rules

- Source of truth is the attached codebases (`material-bluemap` = Worldlens Electron app, `agent-global-memory`). Never invent UI, copy, colors or features from memory — read the repo file first.
- **Every single feature in the codebase must be present and wired in every design here.** No gaps, no "coming soon", no demo-only buttons. Every catalogue, page, job, setting, editor, palette command, notification action and cross-project requirement must be reachable and do something in the prototype.
- Kid/game rewrite targets a 4–6 year old, pre-reading: picture-first, huge hit targets, full playful voice, XP/levels/stickers, celebration moments.
