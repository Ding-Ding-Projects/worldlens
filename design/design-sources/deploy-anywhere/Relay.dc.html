How players reach the server

A Cloudflare tunnel carries the management site and the live map (web traffic). It cannot carry the game itself, which needs raw TCP and UDP ports, so pick a way in for players too.

The relay is a tiny Linux machine that only forwards traffic. The appliance dials out to it over WireGuard, so nothing on your router opens, and the relay never sees the world or any passwords.
