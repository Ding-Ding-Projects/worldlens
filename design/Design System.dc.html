Worldlens

The design system

Every visual decision in this application resolves to one of the tokens below. Nothing in a component hard-codes a corner radius, a shadow, a type size, a state-layer opacity or an animation curve; a component that needs one names the token, and the token is declared once.

The vocabulary lives in tokens.css beside this page, and in the repository as @worldlens/design-system. The desktop app and the served browser shell import the same file — never a second copy — so a colour that changes here changes in a published map in the same commit.

Colour

3 schemes · one role set

Dark and light are generated from the tonal palettes of the blue seed the app has always used. Contrast is deliberately not tonal: it answers the same role names with the highest-contrast values that keep their meaning. Reference the role, never the hex.

Roboto throughout, and Roboto Mono for paths, values, keys, digests and shortcuts — anything the user could be asked to retype. Every value is in rem and no rule anywhere sets a root font size, because interface scale belongs to the interface-size dial, which works through page zoom.
