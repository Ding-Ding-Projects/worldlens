Quick pack

Drop a world folder here. It is copied into a new VHDX beside it, sized to fit, then every file is checked by SHA-256. The folder itself is left alone.

Bayville.vhdxChecking 1,204 of 1,880
Grew from 2.0 GB to 2.6 GB on its own when the files did not fit.
Route: Mount-DiskImage, no Hyper-V needed 
New-Item -Path . -Name Bayville.vhdx ...
Mount-DiskImage -ImagePath .\Bayville.vhdx

Creating, growing and attaching ask Windows for permission each time.
